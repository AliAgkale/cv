Engineering Productivity Toolkit

Conceived and built independently, outside working hours — later adopted within Intesa Sanpaolo

  • Identified a recurring bottleneck at Intesa Sanpaolo: release documentation was consuming 4–8 hours per cycle, written manually from Git history.
  • Independently designed and built an AI-assisted toolkit to solve it — entirely outside working hours, as a personal initiative.
  • Started as a standalone CLI and evolved into reusable scripts and custom AI skills.
  • Automatically analyzes Git changes via git diff between branches or tags, runs a structured AI review of the delta, generates technical documentation and publishes it to Confluence.
